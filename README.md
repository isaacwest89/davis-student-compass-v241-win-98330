## About Davis Student Resource Compass

Davis Student Resource Compass is a responsive web tool built to help UC Davis students discover campus resources more quickly. It combines semantic resource matching with an interactive campus map so users can move from a need to a relevant support option without digging through scattered pages.

The project is designed for a wide range of users, including students who want a clearer view of available help, community members contributing resource entries, and anyone who benefits from multilingual and accessibility-aware navigation. Its predictive suggestions and real-time availability indicators make the experience more dynamic and practical for day-to-day use.

## Features

- Semantic resource matching to connect users with relevant campus support
- Interactive campus map for browsing locations and services visually

- Predictive suggestions to surface likely matches faster

- Accessibility support for more inclusive navigation and interaction

## Usage

Open the web app in a browser and begin by selecting or searching for the type of support needed. The compass will suggest matching resources, show them on the interactive map, and highlight availability details when present.

Typical workflow:
1. Search for a topic or service.
2. Review the suggested matches.
3. Use the map to locate the resource.
4. Switch language or accessibility preferences as needed.
5. Submit a community resource if you want to add or update information.
